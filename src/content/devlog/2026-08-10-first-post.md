## How I built this website:

This site is built with **Astro**, a static site generator, which means it outputs plain HTML that's fast and easy to host. The content is written in Markdown files, and Astro turns them into real pages at build time.

- **Layout & styling:** Astro components (`.astro` files) with custom CSS and a lilac-and-cream theme I picked out.
- **Log entries:** Written in Markdown, stored in the project, and rendered into pages automatically.
- **Deployment:** Astro produces a `dist/` folder of static files that I push to a hosting service like Netlify or Vercel.

It's a full project I'm building step by step — everything from the homepage to this very entry is version-controlled, so I can keep iterating on it as I learn.
